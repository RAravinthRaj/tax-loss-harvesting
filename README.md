# Tax Loss Harvesting

A responsive React + TypeScript tax loss harvesting interface built to match the provided dark KoinX-style UI and interaction flow.

## Features

- Pre-harvesting and after-harvesting capital gains cards
- Holdings table with row selection and select-all support
- Real-time post-harvesting calculations based on selected holdings
- Redux-managed API/data state
- Context API for page UI state like disclaimer expansion and `View all`
- Mock API layer backed by local JSON files in `src/data.json`
- Loader, error state, tooltips, and mobile-friendly layout

## Tech Stack

- React
- TypeScript
- Redux Toolkit
- Context API
- Styled-components
- Vite
